## Before the form

1. Everyone pushes their work. Then run `git fetch origin` and `python scripts/contributions.py refresh`, and
   review the evidence together.
2. Agree the shares and fill in the table. `python scripts/contributions.py check` must print *Every criterion
   totals 100%.*
3. Put the student IDs in a private CSV **outside the repository**, with columns `Member,Student ID`. Then run
   `python scripts/contributions.py check --ids <private.csv> --out <private statement.md>`. It writes the
   form-ready table with IDs and totals, and won't write anywhere inside the repository.
4. Copy that table into the supplied form.
